propertydallals — free real-estate website starter
====================================================

WHAT'S INCLUDED
- Responsive homepage for phones and computers
- Land/plot and flat sample cards with photos and prices
- Search by keyword/location, property type, and maximum budget
- "Post a property" form
- Listing saved locally in the browser
- WhatsApp/phone contact flow for listings with a phone number
- Basic instructions for free static hosting

IMPORTANT LIMITATIONS
- Sample properties are illustrative demo content, not verified real listings.
- The form currently saves listings only in the visitor's browser (localStorage).
  Other visitors will NOT see those listings.
- No user accounts, central database, moderation/admin panel, secure photo uploads,
  email/chat backend, or document verification is connected yet.
- Before public launch, connect a database and authentication, add abuse prevention,
  privacy/terms pages, and remove/replace sample listings.
- The placeholder email address in the footer is not a real inbox.

TEST LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome or another browser.
3. Search listings and use "Post a property" to test the form.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com
2. Create a new public repository named propertydallals.
3. Upload index.html (and this README if desired) to the repository root.
4. In repository Settings -> Pages, choose deployment from the main branch and root folder.
5. Save and wait for GitHub Pages to publish the site.
6. The site address will look like https://YOUR-USERNAME.github.io/propertydallals/
   Replace YOUR-USERNAME with your GitHub username.

This static hosting step makes the site publicly viewable, but does not add shared listing
storage. A backend/database must be added for a real multi-user property marketplace.
